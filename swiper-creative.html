任务二 · Swiper creative effect 自己定义出场姿势

Swiper 官方 effect 只有 6 种（slide/fade/cube/coverflow/flip/cards），隐藏第 7 种——creative。它让你用 transform 自己写 prev / next slide 怎么出场。下面 7 个框，每一个的 prev 和 next 都配了不同的 transform 组合。

① 纯侧移 · next 飞出 100%

translate: [100%,0,0]
prev 在原地留阴影，next 从右侧 100% 飞进来。最基础的 creative 配方。

② 双层夹击 · 左右各 120%

prev -120%, next 120%
prev 向左飞出 -120%，next 向右飞出 +120%，中间叠了两层阴影。

③ 轻推 · prev 只退 -20%

prev translate -20%
prev 只后退 -20%，next 飞进来，层次最温和——企业官网最爱。

④ 3D 翻转 · rotateX 180°

rotate: [180,0,0]
prev 和 next 都沿 X 轴翻转 180° 再推远——教科书式 3D。

⑤ 侧旋 · rotateZ ±90°

rotate: [0,0,±90]
prev 向左转 -90° 退远，next 向右转 +90° 入镜。

⑥ 边缘轴旋转 · origin

origin: left/right center
prev 以左边为轴向右旋转，next 以右边为轴向左转——像翻书。

⑦ 自创配方 · 斜飞 + 缩放

rotate + translate + scale
prev 向左下斜飞并缩小，next 从右上斜飞来带旋转——我自己想的配方。
💡 creative 配方长这样：
creativeEffect: { prev: { shadow:true, translate:[x,y,z], rotate:[rx,ry,rz], scale:[a,b] }, next: { ... } }
prev 定义"当前 slide 离开时变成什么样"，next 定义"新 slide 进来之前在哪里"。想加什么 transform 就加什么——自由度全在你手上。
