任务一 · Swiper 提示词工程 direction: vertical 为什么不生效

两轮 AI 产出并排对比。左边第一轮只写了 direction:'vertical' — 没给容器高度，垂直模式找不到参照。右边第二轮补了 CSS height + pagination verticalClass — 终于可以上下拖了。

第一轮 · ❌ 错 AI 第一次写的

AI 只配了 direction:'vertical'，但 没给 swiper 设 height，垂直模式找不到参照。

JS 初始化代码对比
// ❌ 第一轮（只配了方向）——没用
var yttSwBad = new Swiper('#yttSwBad', {
  direction: 'vertical',   // 方向写了，但容器没高度
  pagination: { el: '#yttPagBad', clickable: true }
});

// ✅ 第二轮（容器有高度 + pagination 也垂直）——生效了
var yttSwGood = new Swiper('#yttSwGood', {
  direction: 'vertical',
  pagination: {
    el: '#yttPagGood',
    clickable: true,
    verticalClass: true   // 小圆点也竖排
  }
});

/* CSS 关键（必须有） */
.demo { height: 320px; }   // 给 swiper 容器一个固定高度
.demo .swiper-slide { height: 100%; }

第一轮提示词

"帮我创建一个 Swiper 轮播，方向是 vertical，有分页器，三张图就好。"
  • ❌ 没说容器高度 → AI 默认 100%
  • ❌ 没说需要 CSS → AI 只写了 JS
  • ❌ 没说 pagination 也要 vertical

第二轮提示词

"请创建一个 320px 高 的 Swiper 垂直轮播（direction:'vertical'），slide 高度占满容器。pagination 圆点也要竖排显示（verticalClass:true）。三张 nature 图，背景图模式，底部加标题和小副标题。给 swiper 容器加一个 320px 固定高度的 CSS 类。"
  • ✅ 指定了容器高度
  • ✅ 指定了 slide 占满
  • ✅ 指定了 pagination 也垂直
  • ✅ 给出了 CSS 要求

🧠 踩坑学到的 5 点

  • vertical 模式必须有高度参照：Swiper 不知道"上下"在哪里——父容器 height 必须明确。
  • 提示词要写完整约束："direction:vertical" 只告诉了 Swiper 怎么滚，没告诉 CSS 容器多高、slide 多高。AI 只能猜。
  • pagination 和 direction 要配对：轮播竖排、分页器还横排视觉会打架。加 verticalClass:true。
  • 先验知识很重要：Swiper 官方文档写了"vertical 模式需要容器高度"——但 AI 不会自动读，得你带上。
  • 验证是最好的老师：拖一下发现它不滚，立刻就知道方向写了但高度没给。
