LLM 实践操作演示

课程实践中的四个 AI 能力模块 · 点击截图可放大查看

MODULE · 01 🤖 AI 客服 · 硅基流动 / 七牛 切换 下拉框 + 对话
前端通过下拉框切换 AI 服务商（硅基流动 / 七牛），后端读取配置即可切换模型来源；
切换后可立即在同一个对话框中发起对话，演示两种 API 响应差异。
🔼 硅基流动 · 对话界面 🔼 七牛 · 切换后对话
MODULE · 02 📚 知识库 · 上传文件 + 功能验证 RAG
用户自行上传文档文件构建向量知识库，随后通过提问验证检索增强生成（RAG）是否正确引用了上传内容。
🔼 文件上传 · 构建知识库 🔼 提问验证 · RAG 检索
MODULE · 03 🖼️ 图像识别 · 上传图片 + 测试 Vision
上传本地图片，调用多模态大模型进行视觉理解，返回识别结果（物体 / 文字 / 场景描述）。
🔼 图像识别 · 上传 → 识别结果
MODULE · 04 🎤 语音识别 · 测试功能 ASR
录音或上传音频文件，通过语音识别（ASR）转文字，验证模型对中文语音的识别准确率。
🔼 语音识别 · 录音 → 转文字
